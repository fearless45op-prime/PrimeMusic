🎵 PrimeMusic

PrimeMusic is an open-source Telegram music bot designed for playing audio in Telegram group voice chats.

✨ Features

- 🎶 Music playback in Telegram voice chats
- 🔎 Song search and playback controls
- 📋 Music queue management
- ⚡ Python-based architecture
- 🐳 Docker deployment support

🛠️ Requirements

- Python 3.10+
- FFmpeg
- Telegram Bot Token
- Telegram API ID and API Hash
- Authorized Telegram assistant session
- MongoDB (for database-dependent features)

🚀 Deployment

1. Clone this repository.
2. Install the required dependencies.
3. Configure the required environment variables.
4. Start the application using the provided Dockerfile or Python entry point.

🔒 Security

- Keep API keys, tokens and session credentials private.
- Use only authorized Telegram accounts.
- Respect Telegram's terms and applicable hosting policies.

📄 Disclaimer

This project is intended for legitimate Telegram voice-chat music playback. Users are responsible for complying with applicable laws, content rights and platform policies.
